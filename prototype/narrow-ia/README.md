# PROTOTYPE — 窄屏 IA（一次性产物，归档分支）

对应 wayfinder 地图 **#40** 的票 **#41 窄屏 IA 原型**。

## 它回答了什么问题

规格 `docs/spec/family-hub-v1.md` §4.2 是**唯一标着「未经验证」**的地方，而它恰恰是家里人最常用的形状。本原型把纸面结构做成能点的东西，并回答票里的五问。

## 三个结构上不同的窄屏导航

| 变体 | 形态 |
|---|---|
| **N1** | 汉堡 + 抽屉 —— 规格的字面：一个抽屉装下全部（面 + 记录 + 身份） |
| **N2** | 底部标签 + 抽屉 —— 面用底部 tab；记录与身份仍在抽屉里 |
| **N3** | 无抽屉 —— 底部 tab；身份在右上头像；会话/阅读记录各自留在面内 |

## 怎么跑

```sh
python3 server/tts_server.py --port 8000
# 把 narrow.html 放回 web/ 即可
# http://localhost:8000/prototype-narrow.html?variant=N1|N2|N3
# 建议用 390×844（手机）与 834×1112（平板竖屏）两个尺寸看
```

## 数据是真的

正文 / 分词 / ruby 来自 `server/data/books/` 已解析章节（《嫌われる勇気》第 62 章，22 句）；中文拼音与释义来自 `server/data/dicts/zh.sqlite`（CC-CEDICT）。AI 回答与持久化是假的，**没有网络请求**。

## 五问的答案（实测）

见票 #41 的决议。摘要：

1. **抽屉与 D3 从不共存** —— 结构上就不可能（D3 全屏，抽屉下没有可达的触发点）。
2. **阅读位置会丢** —— 两个坑：重建 `#main` 重置 `scrollTop`；被 resize 写过的缓存偏移量永久遮蔽实时值。修好后 `1049 → 1049 → 1049`。
3. **底部词卡不遮词** —— 三个变体一致 `covered:false`（开卡后把词滚到卡片上方）。
4. **工具条收起 ✓，但输入框被键盘盖住 ✗** —— 即 iOS Safari 的真实故障模式；**必须复用现役应用已有的 `visualViewport` 处理**。
5. **900px 断点够** —— 834px 命中窄屏（三栏在 834 下只剩 218px 给正文）。

## 一条原型自身的教训

顶栏一度同时出现 `☰` 与 `‹` —— 这两个**不该共存**（根位置是 `☰`，覆盖层有自己的 `‹`）。已修，并写进规格。
