## 它回答了什么问题

**「随时调出 AI」到底是什么动作？** 以及侧栏壳的第一版 IA。

## 赢家：本目录 `r3.html`

```sh
python3 server/tts_server.py --port 8000
# → http://localhost:8000/prototype-shell.html   (把 r3.html 放回 web/ 即可)
```

已定的交互（用户 2026-09-22）：

- AI 对话 = **D3 右侧对话栏**，是**唯一的 AI 对话出口**
- **点一个词 = 直接弹词卡**（读音 / 拼音 + 文中意思），词卡上的「追问 →」**开 D3**
- **拖选一段 = 工具条**：复制 / 马克笔 / 写想法 / **AI问书**
- **AI问书 → D3**：面板里**引用选中原文**，并给出可直接执行的默认 prompt（`断句解析` / `逐词解释` / `语法点` / `翻译成中文`）
- 侧栏：**可收起**；Chat 下方是**会话记录**，Read 下方是**阅读记录**
- Read：没读过 → 书架（分类 + 导入）；读过 → 默认打开上次的阅读
- 身份 chip：一个，标题「**现在是谁**」，副标题列出它换的是整套（书 · 进度 · 词表 · 对话）

### 一个实现层的发现

正文里每个字都在词 span 里，**所以「点一句」永远点不到**。查词与问书的分流**只能靠选区长度**：短选（≤3 字）= 词 → 词卡；长选 = 段 → 工具条。

## 数据是真的

`r3.html` 里的正文 / 分词 / ruby 取自 `server/data/books/` 已解析的章节（《嫌われる勇気》第 62 章、《红楼梦》第十七回）；中文词的拼音与释义取自 `server/data/dicts/zh.sqlite`（CC-CEDICT）。AI 的回答、会话与阅读记录、划线/想法的持久化都是假的，没有网络请求。
