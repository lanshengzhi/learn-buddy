# 截图 —— 三轮原型的视觉记录

一次性产物，随原型一起归档。**每张都是 Playwright + 本机 chrome 实测渲染的**（1440×900 @2x）。

| 目录 | 轮次 | 内容 |
|---|---|---|
| `r1/` | 第一轮 | `A` 常驻右栏 / `B` 浮层抽屉（含 `-open`）/ `C` 就地内联（含 `-thread`）/ `chat` 面 / `lookup` 词卡 —— **三个变体全部落选** |
| `r2/` | 第二轮 | `shelf` 书架 / `mini` 收起侧栏 / `drag` 拖选工具条 / `dict` 真拼音词卡 / `D1` 底部抽屉 / `D2` 锚定浮层 / **`D3` 右侧对话栏（胜出）** |
| `r3/` | 第三轮 | `selbar` 工具条 / `ai-presets` AI问书引用+预设 prompt / `ai-ran` 执行预设 / `word-C1` 卡内追问 / **`word-C2` 词卡→D3（胜出）** / `mark-note` 马克笔与想法 |

⚠️ **`r2/` 的截图是第二轮唯一的存世痕迹** —— 那一轮的源码在写 r3 时被覆盖丢失了；本目录存在的部分原因就是补上这个损失。
