# 一次性原型：阅读与查义界面（issue #12）

**这不是产品代码。** 用来回答「一本书进到 LearnBuddy 之后长什么样、怎么用」；结论记入 ticket 后，原型留在这条 throwaway 分支上即可。

## 跑起来

```bash
cd prototype/reader-lookup-ui
python3 -m http.server 8099
# PC:    http://localhost:8099/
# 平板:  http://192.168.3.15:8099/   （与本机同网时）
```

URL 参数（可选）：`?v=1|2|3` 版式、`?g=hold|select|tap` 手势、`?book=alice|kumo&ch=0` 选书。

## 要看的四件事（对应 ticket 的五个问题）

1. **版式** —— 顶部「原型控制」切换：V1 沉浸（底部抽屉）、V2 双栏（宽屏右侧常驻查义/目录栏，窄屏回落抽屉）、V3 卡片（沿用现有句子卡片，查义用贴着词的浮层）。
2. **手势共存** —— 长按 / 划选 / 点词三选一：同一段文字上「点句朗读」与「查词」如何不打架。平板重点试长按（会不会触发系统选字/滚动），PC 重点试划选。
3. **查义卡** —— 放哪（抽屉 / 侧栏 / 浮层）、放什么（读音、释义、上下文句、「问 AI」按钮）、查不到时的样子。
4. **续读** —— 滚动到某处 → 刷新页面 → 应回到原位置并提示「已回到上次阅读位置」；「清除阅读位置」可重置。
5. **编辑器共存** —— 读书模式下编辑器收成底部一条（点击可展开），与现有单页布局（ADR 0003）的关系。

## 已知的假东西（别当真）

- 播放是假的：只有高亮、加载圈与计时，没有音频。
- 词典是内嵌样例词条（英/日两个样本），未收录的词会显示「未收录」——那是有意暴露的状态。
- 日文切词用 `Intl.Segmenter` 粗切；真实实现应为服务端 Sudachi + JMdict（见 #11）。
- 阅读位置存 localStorage，仅为演示「打开即续读」。
